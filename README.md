# CurcumaMaster 🌿
### Precision 1-Acre Turmeric Agronomy & Profitability Suite
*(Karnataka & South India Agro-Climatic Zones)*

CurcumaMaster is a scientific web application and agronomic decision-support platform designed for 1-acre precision turmeric cultivation. Built upon field trials and recommendations from **ICAR-IISR Kozhikode**, **UAS Bengaluru**, **UAS Dharwad**, and **KAU**.

---

## 🌟 Core Features

- **Scientific Yield Benchmarking:** Comparison of conventional 4-tonne (4,000 kg) rainfed baseline vs. 12–16 tonne precision drip-fertigated targets.
- **Biophysical Clump & Soil Simulator:** Interactive real-time calculator modeling single-clump mass (kg), subterranean density (kg/m²), and biophysical feasibility.
- **Elite Variety Selection Matrix:** In-depth trade-off comparisons for *IISR Pragati* (180 days, 5.02% curcumin), *IISR Prabha* (195 days, 6.52% curcumin), *IISR Alleppey Supreme* (210 days, 20.5% dry recovery), and *Salem/Erode Local*.
- **Broad Raised Bed (BBF) Geometry:** 3D bed architecture (120 cm width, 25–30 cm height, 30 cm drainage furrows) and seed sett calculator.
- **Precision Drip Fertigation Engine:** Stage-by-stage water volume (litres/day) and water-soluble fertigation schedule (Urea, 19:19:19, 12:61:00, 13:0:45, 0:52:34, 0:0:50 SOP, CaNO₃, MgSO₄).
- **9-Month Operational Crop Calendar:** Month-by-month and DAP-wise agronomic task checklist from land preparation to harvest.
- **Integrated Pest & Disease Management (IPDM):** Diagnostic and control guides for Rhizome Rot (*Pythium* / *Ralstonia*), Shoot Borer, Leaf Blotch/Spot, Nematodes, and Scales.
- **1-Acre Commercial Budget & Net Profit Simulator:** Live sliders for fresh harvest yield, dry recovery %, APMC dry price, fresh farmgate price, and production costs with BCR and break-even calculations.
- **Dark/Light Mode & Print-Ready Blueprint:** Full responsiveness and print styling for offline field handbooks.

## 🚀 Getting Started

### Prerequisites
- Any modern web browser (Chrome, Edge, Safari, Firefox).
- [Node.js](https://nodejs.org/) (optional, only needed for local dev server).

### Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/satishbiradi03-bit/prajwal.git
   cd prajwal
   ```
2. Start the lightweight server:
   ```bash
   node server.js
   ```
3. Open your browser and navigate to:
   ```
   http://localhost:5173
   ```
   *(Or simply open `index.html` directly in any web browser).*
